Notes

Data is based on the NEOFixer website. This includes all NEO, NEOCP and PCCP objects. 

The visibility of objects is estimated by NEOFixer for the current or upcoming night at each of the observatories (E62, G40, W88). 
Score is a NEOFixer expression representing how worthwhile observations would be based on a variety of factors. Unc is a numerical parameter based on the MPC "U" parameter, but can include negative values for objects with extremely well defined orbits.

To obtain Ephemeris:

  • Set the field "Hours +/- to start of Ephemeris" to the number of hours from "now" until the Ephemeris should begin.
  • Select which objects you want ephemeris for using the check-boxes.
  • Press the NEO or NEOCP Ephem button below the list.

Ephemeris will be shown at 30m intervals from the selected start time and for a time span roughly equivalent to the length of astronomical darkness at the observatory.
